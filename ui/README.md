# UI

Screens and components. They read data and engine results and display them. They never calculate.

- Colors, type, spacing, and radii come only from [`tokens.css`](tokens.css).
- Components are defined in [`docs/design-system.md`](../docs/design-system.md) before they're built.
- Words follow [`docs/style-guide.md`](../docs/style-guide.md).
